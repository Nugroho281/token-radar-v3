Azimuth — a token launch radar. Thirteen model variants run on one walk-forward protocol over the snapshot's 128 traded comps (the previous entry's four kept as controls, nine challengers); the winner, a two-segment size curve with a growth term, posts a walk-forward median |log10 error| of 0.4399 against the previous winner's 0.4470 and prices all 197 genuine pre-token protocols with bootstrap bands and rank ranges. The no-token clock is tested in three forms, shown on every row, and — on the walk-forward evidence — priced into none. Every row is decomposed into its model parts, shown against its nearest traded tokens, and carries a dated farm plan netted to the dollar: farm, thin or skip.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /path/to/snapshot.json
```
